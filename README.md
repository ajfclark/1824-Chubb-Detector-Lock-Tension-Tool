# 1824-Chubb-Detector-Lock-Tension-Tool
A tension tool for Rocco's Stuff's 1824 Chubb Detector Lock on printables.

You can get the model for this from Printables: https://www.printables.com/model/1150379-1824-chubb-detector-lock

## Printing

I print this at 100% infill.
